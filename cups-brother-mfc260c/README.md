# CUPS Druck- & Scanserver (Brother MFC-260C)

![Architektur](https://img.shields.io/badge/arch-amd64-blue)

Druck- und Scanserver für den per USB angeschlossenen **Brother MFC-260C**.

- Drucken per AirPrint / IPP Everywhere – ohne Treiber auf deinen Geräten
- Scannen per AirScan / eSCL, auch im Browser über die HA-Seitenleiste
- Scan-Menü am Gerät speichert direkt in einen Ordner, auf Wunsch mit
  Texterkennung
- Druckordner: Datei hineinlegen, sie wird gedruckt

Basiert auf CUPS / Legacy Printer Application (OpenPrinting), AirSane und
SANE. Der Drucker wird beim Start automatisch eingerichtet. Alles Weitere steht im
Tab **Dokumentation**.
